# 三星软重启流畅优化 (原生调度纯净版)

针对 Samsung Galaxy 系列 One UI 在软重启（用户空间重启 / userspace-reboot）后出现的掉帧、卡顿与锁屏时间丢失问题进行平息与修复的 KernelSU 模块。

---

## 核心特性

* **修复锁屏时钟丢失**：开机自动拉起并绑定 `AODService`，解决软重启后官方原生锁屏时钟空白与 Binder 握手超时问题。
* **平息内核套接字风暴**：优化 `tcp_tw_reuse` 与套接字队列，解决 `kworker` 高频抢占 CPU 导致的系统发热与掉帧。
* **抑制安全日志洪泛**：限流内核 `printk`，降低 Knox / DEFEX 拦截产生的系统审计开销。
* **优化虚拟内存换页**：调优 `swappiness` (100) 与 `vfs_cache_pressure` (80)，缓解高负载下 ZRAM 剧烈换页与 `sys CPU` 占用。
* **精准进程清理**：仅清理 CVE 临时提权残留的临时二进制文件，对系统原生组件零误杀。
* **原生调速纯净**：不破坏系统服务，完全保留三星官方原生的能效曲线与动态调速策略。

---

## 兼容性与运行环境

* **Root 方案**：KernelSU (支持临时 Root，软重启不掉 Root)
* **系统环境**：Samsung One UI 8.5

## 更新日志 (Changelog)

**v1.5.3**
* 修复锁屏时钟丢失：开机自动拉起并绑定 `AODService`，解决软重启后官方原生锁屏时钟空白问题。
* 调优虚拟内存参数：调整 `swappiness` (100) 与 `vfs_cache_pressure` (80)，抑制后台服务换页颠簸与 `sys CPU` 占用。
* 优化启动延时：开机等待时间从 30s 缩短至 15s，更快平息网络与日志风暴。

**v1.5.2**
* 精准进程清理：仅清理 CVE 提权产生的临时二进制进程，彻底杜绝误杀系统组件。
* 抑制日志洪泛：限流内核 `printk`，降低安全审计拦截带来的系统负载。
* 平息网络风暴：优化 `tcp_tw_reuse` 与网络套接字队列，解决 `kworker` 高频抢占 CPU。

**v1.5.1**
* 保留原生调速：删除了强行重置调度策略的逻辑，完全沿用三星官方原生能效曲线。

**v1.5.0**
* 杜绝硬重启：移除了所有的 `am force-stop` 逻辑，防止因 `system_server` 跨进程崩溃触发 Watchdog 导致手机硬重启并丢失临时 Root。
