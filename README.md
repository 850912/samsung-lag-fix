# 三星软重启流畅优化

针对 Samsung Galaxy 系列 One UI 在软重启（用户空间重启 / userspace-reboot）后出现的掉帧、卡顿与锁屏时间丢失问题进行平息与修复的 KernelSU 模块。

---

## 核心特性

* **彻底修复锁屏时钟与 AOD 丢失**：开机自动通过前台服务与系统广播拉起并绑定 `AODService`，解决软重启后官方原生锁屏时钟空白与组件脱机问题。
* **平息内核套接字风暴**：优化 `tcp_tw_reuse` 与套接字队列，解决 `kworker` 高频抢占 CPU 导致的系统发热与掉帧。
* **抑制安全日志洪泛**：限流内核 `printk`，降低 Knox / DEFEX 拦截产生的系统审计开销。
* **抑制框架层服务重启风暴**：动态注入全局调度参数，拉长高频崩溃后台的重试惩罚间隔，根治 `system_server` 高 CPU 占用死循环。
* **优化虚拟内存换页**：调优 `swappiness` (100) 与 `vfs_cache_pressure` (80)，缓解高负载下 ZRAM 剧烈换页与 `sys CPU` 占用。
* **白名单极速进程清理**：利用临时目录白名单机制毫秒级定向清理 CVE 提权残留，杜绝误杀 S-Pen 及系统原生组件。
* **原生调速与电池策略保留**：不破坏系统服务，完全保留三星官方原生的能效曲线、电池优化与调度策略。

## 安装教程

### 方式一：管理器直接刷入（推荐）

1. 前往本仓库的 **[Releases 页面](../../releases)** 下载最新的 `samsung_lag_fix_v1.5.8.zip` 刷机包。
2. 打开 **KernelSU** 管理器。
3. 进入 **「模块」** 界面，点击 **「+」**。
4. 选择下载好的 `.zip` 文件刷入。
5. 刷入完成后，**切勿执行完整关机重启**（临时 Root 会掉），直接在管理器内点击 **「软重启」**。

## 兼容性与运行环境

* **Root 方案**：KernelSU (支持临时 Root，软重启不掉 Root)
* **系统环境**：One UI 8.5（适配包含 S-Pen 的 Ultra 系列及全系 Galaxy 机型）

* **重构锁屏时钟与 AOD 唤醒链路**：改用 `--user 0` 显式主用户前台服务拉起机制（`start-foreground-service`），并新增 `TIME_SET` 与 `AOD_STATE_CHANGED` 系统广播强制触发视图重绘，彻底解决软重启后官方锁屏时钟空白、丢失问题。
