# Samsung Galaxy 语音助手自愈与系统维护模块

针对 Samsung Galaxy 系列（One UI 8.5 / Android 16）在国行固件或临时 Root 软重启后可能出现的语音交互绑定丢失、残留进程滞留与状态异常进行自愈与诊断的 KernelSU 模块。

> **设计原则**：本模块不以修改系统性能参数为目标，而是针对软重启后的系统状态异常进行低风险自愈与诊断。不再包含任何内核调度、虚拟内存（sysctl）、网络栈等高风险参数修改。

---

## 核心定位

* **核心修复**：解决国行固件重启后 Google 语音助手服务（`voice_interaction_service`）丢失、侧键无法唤醒的问题。
* **辅助维护**：安全扫描并清理临时 Root 提权后滞留在临时目录下的已知残留进程。
* **状态检查**：开机检查 `system_server`、`surfaceflinger` 核心进程运行状态及可用内存。
* **纯净安全**：完全保留三星原生调度、温控、能效曲线与电池策略，不篡改系统性能底层。

---

## 核心特性

### 🎯 Google 语音助手开机条件自愈 (Core)
* **动态条件判断**：开机阶段读取系统 `role.ASSISTANT` 与 `secure assistant` 配置。
* **零误触设计**：仅在检测到用户主动将默认助手设为 Google 时，自动补全底层丢失的 `voice_interaction_service` 绑定；若设置为 Bixby、小爱同学或未设置，模块自动跳过，不干预任何系统配置。
* **状态自愈**：针对因 `voice_interaction_service` 绑定丢失导致的语音助手唤醒异常进行自动恢复；已实测可解决相关 ActivityTaskManager `-92`（`START_NOT_ACTIVITY`）启动失败问题。

### 🛡️ 已知临时 Root 残留进程清理
* 系统启动就绪（`sys.boot_completed=1`）并等待 5 秒框架就绪后介入。
* **路径白名单 + 精确进程识别**：仅扫描 `/data/local/tmp`、`/data/tmp`、`/dev` 等临时目录下的已知提权进程。
* 坚决不使用全局 `pkill -f` 或 `killall` 模糊扫描，避免误杀 S-Pen 硬件服务、系统关键服务及电源管理组件。
* 降低异常后台进程持续运行、占用系统资源的风险。

### 🔍 关键系统服务与运行环境检查
* 检查 `system_server` 与 `surfaceflinger` 核心进程是否正常运行，并记录 PID。
* 记录系统启动等待耗时与 `MemAvailable` 可用内存状态。

### 📊 一键导出诊断日志（Action 触发）
* 支持在 KernelSU 管理器中通过“执行”（Action）直接生成完整诊断报告。
* 报告自动导出至 `/sdcard/Download/Samsung_LagFix/`，包含基础设备信息、Voice Assistant 绑定状态、关键进程及内存数据。

## 安装与使用

### 安装方式
1. 从 Releases 下载最新版本的模块 ZIP。
2. 打开 KernelSU 管理器，进入「模块」界面。
3. 点击右上角「+」，选择模块 ZIP 并刷入。
4. 刷入完成后根据实际需要重启设备。

> ⚠️ **注意**：如果使用的是临时 Root，冷关机或硬重启可能导致 Root 状态丢失。本模块无法使临时 Root 永久化。

### 导出诊断日志
1. 打开 KernelSU 管理器，找到本模块。
2. 点击模块界面的「执行」（Action）按钮。
3. 日志将自动生成并导出至：`/sdcard/Download/Samsung_LagFix/Samsung_LagFix_<时间戳>.log`。

---

## 卸载

在 KernelSU 管理器中直接禁用或删除本模块，重启手机即可完全移除。模块不会在系统分区残留任何持久化配置。

## 注意事项

* 本模块为针对特定系统状态异常的自愈工具，**不是通用性能加速/调度优化模块**。
* 不建议与其他修改 CPU 调度、内核 VM 参数、网络栈的性能模块混用，以免破坏系统稳定性。
* 如遇异常情况，建议先通过 Action 导出运行日志，再行禁用模块排查。
